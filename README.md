# Data Exploration in SQL  
**COVID-19 data exploration project using SQL — analyzing infections, deaths, and vaccination progress.**

---

## Project Overview
This project explores global COVID-19 data using SQL.  
The goal was to analyze trends in infections, deaths, and vaccinations, and derive insights at both country and continent levels.

### Objectives
Using SQL, I performed various exploratory steps to understand the spread and impact of COVID-19. The analysis includes:
- Examining total cases, deaths, and population data  
- Calculating death percentages and infection rates  
- Identifying countries and continents with the highest impact  
- Exploring global trends over time  
- Analyzing vaccination progress against population  

---

## Files in this Repository
- **Data Exploration in SQL.sql** – Main SQL script containing all analysis steps with comments  
- **data/** – Folder containing source data files 

---

## Data Files
This project uses data sourced from [Our World in Data](https://ourworldindata.org/covid-deaths).  

For the SQL joins, the dataset was split into two Excel files:
- `CovidDeaths.xlsx` – Contains information about cases, deaths, and population.  
- `CovidVaccinations.xlsx` – Contains vaccination data.  

Both files can be found in the **data/** folder.

---

## Tools Used
- Microsoft SQL Server (SSMS)  
- COVID-19 dataset from [Our World in Data](https://ourworldindata.org/covid-deaths)

---

## Key Insights
- Countries with smaller populations but higher infection rates show greater proportional impact  
- Death percentages vary widely across regions, influenced by testing rates and healthcare capacity  
- Global fatality rates declined as vaccination coverage increased
